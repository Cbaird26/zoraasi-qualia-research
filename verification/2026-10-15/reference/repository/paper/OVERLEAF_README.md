# Overleaf-ready scientific manuscript

Upload `main.tex` alone to a new Overleaf project, set **Compiler: pdfLaTeX**, and click Recompile. All citations are contained in `thebibliography`; no external .bib file or figures are required. The local release bundle's PDF was generated with `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex` and visually checked. Before scholarly submission the human author should confirm the final byline, affiliations, funding/conflicts, license and scholarly positioning. This is a research software preprint draft, not peer reviewed.

This GitHub release initially publishes the `.tex` source. A matching compiled PDF is in the separately supplied public-candidate release archive, but is not claimed as hosted on GitHub unless an actual PDF file appears in this repository. The paper describes only the synthetic connection study; unrelated copyrighted source texts, private chat and unvalidated consciousness-field claims are excluded.
